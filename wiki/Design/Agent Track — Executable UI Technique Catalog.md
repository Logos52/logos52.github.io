# Agent Track — Executable UI Technique Catalog

Machine-consumable design rules — the part of UI a design/coding agent can apply deterministically without taste. Populated by the process in [[wiki/Design/Design Two-Track Extraction|Design Two-Track Extraction]]. Each entry should be atomic, prescriptive, and checkable; aim for rules an agent could lint against. The judgment edge of any rule lives in [[wiki/Design/Human Track — Taste & Judgment Catalog|the Human Track]], cross-linked at the seam.

**Entry shape:** `Rule — concrete parameters / values — when it applies — (seam → Human Track if judgment-dependent)`
