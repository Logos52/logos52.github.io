# Design, Condensed

Don Norman's book The Design of Everyday Things explains why doors, stoves and screens confuse people. The book puts the fault for that confusion on the design and takes it off the person using the thing. The rules below are the book's rules, one per line, and each can be checked against a real object in a few seconds.

- When people struggle with an object, look first at the design.
- A person should see what they can do and what just happened.
- Put the knowledge in the object so nothing has to be remembered.
- Expect errors, and make them easy to undo.
- Watch people use the thing before deciding what to build.

## The rules

Using any object runs in two directions. A person works out what to do and does it, then looks at what changed and works out what it means. Norman calls the gap in the first direction the gulf of execution and the gap in the second direction the gulf of evaluation. Most of the rules below narrow one gap or the other.

- Finding what to do
  - An affordance is what an object lets a person do.
  - A signifier shows where and how to act, like a push plate.
  - Set controls out in the pattern of what they change, like stove knobs.
  - A constraint stops a wrong move, like a plug that cannot go in wrong.
  - A forcing function blocks the next step until the last is done.
- Seeing what happened
  - Respond at once, since a tenth of a second already feels slow.
  - Too much feedback is as bad as none.
  - The object alone must show how it works.
- Memory
  - Working memory holds about three to five items.
  - Show everyday steps on the object and keep shortcuts for experts.
- Error
  - What gets called human error is usually a design error.
  - A slip is the right goal with the wrong action.
  - A mistake is the wrong goal or the wrong plan.
  - Make similar controls look different, and show which mode is on.
  - Make actions reversible, since undo is the strongest tool.
  - Make the irreversible hard to do.
- Process
  - Find the right problem before solving it.
  - Observe, make ideas, prototype, test, and repeat.
  - About five testers per round finds the repeated failures.
  - Features added and never removed make a product worse.
  - A known standard can beat a better layout nobody knows.
