# Human Track — Taste & Judgment Catalog

What the eye must judge — the part of design that doesn't reduce to a rule an agent can run. This is the catalog Wedge actually *reads and looks at*: the techniques where applying them well requires perception, context, or taste, and where an agent can produce a candidate but not tell whether it's good. Populated by the process in [[wiki/Design/Design Two-Track Extraction|Design Two-Track Extraction]]. The mechanical core of any technique here lives in [[wiki/Design/Agent Track — Executable UI Technique Catalog|the Agent Track]].
