# Retrieval

Retrieval is pulling knowledge out of memory and using it: recalling a fact, explaining an idea, solving a problem, or teaching someone. Unused memory fades. Retrieval practice slows the fading, catches errors, and prepares knowledge for use under pressure.

## Takeaways

- Self-testing beats rereading on any delayed test.
- Most learners still choose rereading, because it feels smoother.
- Effort during recall feels like failure but builds memory.
- Space practice out and vary its form.
- Use retrieval to find weak spots, then study those.
- Match each method to a kind of knowledge.

## How it works

Every recall rebuilds and strengthens a memory, and every failed recall shows a gap. Rereading feels productive because material seen again looks familiar, but the familiarity fades quickly once the notes are closed. Testing yourself feels harder and less pleasant, and learners tend to read that difficulty as a sign the method is failing. On tests given days later, people who tested themselves remember more and apply it better to new questions.

- Rereading wins only on a test given right away.
- It also raises confidence more than it raises recall.
- Harder forms of recall push the learner to think more deeply.
- Facts, skills, and knowing when to use each need different methods.
- Practising retrieval uses different methods from first learning.

## Where it connects

A failed recall can mean a memory faded, or that it was never built well. A memory never built well is an encoding problem, and encoding is covered under deep processing. Whether a learner treats a failed recall as useful information or avoids it depends on mindset and self-regulation. Spacing only works if sessions happen on schedule, which is a self-management job.

- Dunlosky, J., Rawson, K. A., Marsh, E. J., Nathan, M. J., & Willingham, D. T. (2013). Improving students' learning with effective learning techniques. *Psychological Science in the Public Interest*. Practice testing rated high utility.
