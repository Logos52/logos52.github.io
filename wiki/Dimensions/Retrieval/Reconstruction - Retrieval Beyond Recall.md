# Reconstruction: Retrieval Beyond Recall

Reconstruction is a way of testing yourself in which you take facts you already know and try to join them in ways you have not joined them before. Plain recall checks only that a memory you built can be brought back. Reconstruction checks whether those facts still work in a new arrangement, which is what hard and unexpected exam questions ask for.

## Takeaways

- Recognising is weaker than recalling, and recalling is weaker than reconstructing.
- Reconstruction builds new links between facts you already hold.
- Each proposed link has to be judged: possible or not.
- It finds gaps that recall leaves hidden.
- It takes longer, so mix it with recall.
- Use more of it early, more recall later.

## Three levels of testing

Recognition means picking a correct answer from options shown to you, and it tests almost no mastery. Recall means producing the answer with nothing shown, and how deep it goes depends on what is recalled. Recalling a fact is shallow, recalling an explanation is deeper, and recalling how to solve a problem is deeper still. Reconstruction sits above every kind of recall because it asks for something that was never stored.

```
reconstruct   build a new valid link     judge, create
recall        rebuild a known answer     explain, apply
recognise     pick from options shown    little
```

- Recall practice beats recognition practice on later tests.
- Reconstruction also exercises recognition and recall along the way.
- In Bloom's ranking of thinking skills, it works at judging and creating.

## Why it works

A memory is a set of pieces held together by the relations between them, and every act of remembering builds it again from those pieces. Since remembering is always a rebuild, the most direct test is to rebuild in a new way. To say whether a new link holds, you have to know each piece well enough to see what it can and cannot connect to.

- Building a new structure is itself a way of learning it.
- A fan can easily imagine two characters from different stories meeting.
- Study material can be used just as freely.
- A feeling of knowing is a poor sign of real mastery.

## How to use it

Take a set of points from a topic and try to join them in pairs or groups you have not joined before. For each join, say whether it is valid and why, or why it cannot work. When a join that should work fails, that point is weaker than it felt. Those gaps go into revision.

- Ask how one idea would change another it was never compared with.
- Ask which two ideas cannot be linked, and why.
- A failed link marks a gap to fix.
- Past papers test recall and application but miss these gaps.
- Unexpected exam questions give familiar pieces in an unfamiliar shape.
- Knowledge used in a new form often fails without this practice.

## Balancing it with recall

Reconstruction is slower than recall, so most learners use both. Some find about 10% recall and 90% reconstruction efficient, and others prefer an even split. Early in learning a topic, reconstruction finds many gaps quickly. Later, recall sharpens the details.

- Early phase: mostly reconstruction, for fast gap finding.
- Later phase: more recall, for detail and speed.
- Pick the mix you can keep up.
