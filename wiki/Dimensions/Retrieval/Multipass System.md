# Multipass System

The multipass system uses a picture of stacked layers that each have holes. The different passes are like those layers, and they let you cover almost all of the material in just a few days. Each pass is one sweep through the material.

A related foundation is a system of core skills and steps for taking in any new material, and for thinking about and processing that information so knowledge is encoded efficiently, meaning stored in a usable form. Each learning session still uses those steps. Multipass is a strategy for deploying them in different ways. It adds advice on when to study and a broad steer for the order you meet material in. It tells you what each sitting will cover and how to break a topic into manageable blocks. That is especially useful for big, packed topics that will take more than one pass. Other ways of using the same core skills are mentioned and not described here.

There are two ways to perform the system.

Inquiry-led multipass lets relevance come from your own inquiry process. It feels natural and engaging. It is an extension of the usual core-skill sequence, split across several sittings, each one taking a changing number of learning layers. It can be less strategic when time pressure is high. It suits rapid learning of high volumes when time is more flexible, and material that needs to be fundamentally strong for later learning and application.

Objectives-led multipass lets learning objectives dictate the order. Learning stays directly relevant to most assessable material, and time spent is very likely to translate into performance results. It trades some of the quality of encoding, meaning how well the knowledge is stored, for performance strategy. That can reduce retention and the ability to handle the most higher-order or unanticipated questions. It suits imminent time pressure that demands high volumes of learning with little study time, and topics with limited long-term relevance.

Both approaches start with the logic layer and the concepts layer. Ordinary cramming starts with detail layers whose relevance goes up and down.

Whichever approach you use, emphasising those first layers helps prepare you for assessments. Most questions come out of logic and concepts, so it is much easier to extend what you know and answer a wide range of questions.

If there is time, adding some interleaving is also recommended, preferably a method such as WPW. You may also need to add a lower-order memorisation method such as flashcards at the same time.
