# Opportunistic Retrieval

The day's work retrieves the material, so planned sessions shrink to the slice the day never asked. A Tuesday heart case pulls Monday's notes the same way a ticket, a client, or an afternoon class does — each use is a real rep, one pull from memory, delayed by the job calendar and mixed by the day, at zero extra study time. Opportunistic retrieval names that workflow: the work is the session, then an audit of what went untested, then planned study only on the remainder, none when the job uses the material in the learned form.

## After the day

**Label the rep.** After work uses studied knowledge, a short note records what just happened. Without the label the use is still a real rep; the label is what makes the missed slice visible. That note is a retro-label: after the fact, which order and which type the task actually demanded.

**Read the gap.** The order check asks whether the task demanded higher-order use — building a strategy, evaluating a plan, synthesising a picture — or lower-order use, facts and a known procedure. A day handled only at recall leaves the higher-order memory untested. Those order and type labels come from [[Higher-Order Learning]]; this page uses them and does not re-derive them. The type check asks whether the knowledge was exercised declaratively (stating, explaining) or procedurally (doing), and whether that match is how it must eventually perform. Whatever the day did not exercise is the open gap, located without a test question. Untested is not the same as weak: the day showed what was untested, not what is broken.

**Close it, or don't.** A labelled gap has two repairs and one honest exit. A targeted planned session is a small deliberate block aimed only at the slice work skipped, usually the higher-order layer. Method choice lives in [[Spaced Interleaved Retrieval]] and the [[Interleaving Table]]; this page does not teach formats. Convert the work instead when the next task can be reshaped to demand the missing order: draft the strategy rather than run someone else's, critique the plan just written, take a whole-case view before acting. Time pressure and job responsibilities often forbid conversion — the task gets done the one way it can, and the next one starts. The reps were still free; only the top-up was lost.

## When planned retrieval can stop

A course still requires scheduled retrieval. Daily professional use flips the job: the sessions already happened at work, and what remains is an audit of what those sessions missed. Close transfer — the job uses the material in the same form it was learned for — is the only condition under which planned retrieval can fall to none. Far transfer is not free, so that none stays attached to the condition. A reader still inside a course still needs planned [[Spaced Interleaved Retrieval]]; this page is not permission to drop those sessions. [[Encoding and Retrieval]] decides how many reps the knowledge needs at all: they can fall, and they never always reach none unless transfer is close.

## Before the week

**Study what the work will test.** Work assigns its own tasks; the weekend before is still choosable. Study is sequenced by the retrieval opportunities coming up, not by curriculum order. The forecast question comes first: what the next few weeks will force to be recalled, and which knowledge type they will demand. That material is learned first, even if a course teaches the other topic first — heart material now because the ward is cardiology, or the upcoming ticket queue before an elective still months out. Daily cases then supply reps no schedule could match.

**Insert a missing order.** When routine tasks only exercise one level, an activity inserted into the workweek tests another — a review, a write-up, a design critique. Teaching a junior is the same insertion at higher order: the whole topic has to be structured, live questions fielded, picture and detail moved between, and the team gets something besides a study hour. [[WPW]] is the structured form of that teaching; it is optional, not required.

**Stop at the goal.** Holding memory well above the actual requirement spends the hours this workflow exists to recover. For a low-stakes topic — one isolated problem, one client talk, a pass-only elective — the bar has a shape: the questions can be answered, leakage is modest, some retention depth is there. Ordinary daily use on its own may already clear that bar. Knowledge that will have to become real expertise later still earns long-horizon hold and depth now, even when today's assessment asks almost nothing of it. The labelling habit is the price. Converting every task, or topping up slices that were only untested, is the quit signal. A working week leaves planned sessions only on the slices the days did not touch.

The work ran the session. The only study left is what the day never asked.
