# Problem-First Learning

Problem-first learning starts a topic from the problems it solves and learns the theory in order to solve them, instead of learning the theory first and looking for problems afterwards. It is aimed mostly at maths and similar subjects, where students often memorise equations and practise until each question type works, and then fail on any question worded in a new way. A student who knows what each idea is for handles new and applied questions more easily.

## Takeaways

- Start with what a topic is for, then learn how it works.
- Ask what each idea is, why it matters and how it relates.
- Map the uses of a concept before learning its equations.
- Practice alone teaches only the question types practised.
- Practice after the map teaches more per question.
- Writing hard questions of one's own tests the map.

## Why the usual order fails

The usual way to learn maths is to skim a little theory, move quickly to the equations, and then drill practice questions. That builds procedure without understanding, so each equation works only in the setting it was practised in. A student who has practised ten question types can answer those ten and struggles with the eleventh. People who are strong at maths know why each equation exists, and that tells them when to use it.

- Each practised question covers only its own type.
- Drilled procedure breaks down on applied, worded questions.
- Knowing why an equation exists shows when to use it.

## How to do it

The learner begins by listing the topic's main concepts, equation types and keywords, taken from the syllabus, summary notes or an encyclopedia. For each item they ask what it is, why it matters and how it relates to the others, and they start with its real uses. The answers go on a simple map that shows how the parts connect and what each one is used for. Equations and calculation come after the map, and practice comes after those.

```
problem   what is this topic used for?
   |
map       concepts, their uses, how they link
   |
method    equations and calculation steps
   |
practice  each question tests the map
```

- Build the keyword list from the syllabus and summary sources.
- For maths, ask "why does this matter" first.
- Drop a source that does not answer the current question.
- Expect the first pass to feel slow and crowded.
- Map every way a concept can be applied.
  - In calculus: tangents, maximum and minimum points, areas, rates.
- Move to equations once each part's purpose is clear.

## Practice after the map

Practice is still needed, and the amount does not shrink much. What changes is what each question does. With the map in place, each question is a test of a guess about how the maths works, and a wrong answer corrects the map in place of adding one more memorised procedure. The final check is to write hard, realistic questions that combine several equations.

- Treat each practice question as a test of the map.
- Write applied questions that need several equations together.
- Trouble writing such questions means the map has gaps.
- Go back to the map and rebuild it, then try again.

## Limits

Research on teaching complete beginners finds that worked examples usually teach a procedure better than solving problems unaided. Problem-first learning keeps that finding: the problem sets the purpose, and the method is then studied with full guidance. A short, bounded attempt at an unsolved problem before instruction can help understanding. Classroom problem-based learning with little guidance is a different design and often does worse.

- The method is still taught in full once the problem is set.
- A skill practised in a single way transfers poorly to new problems.
- Unguided discovery is not the aim.
