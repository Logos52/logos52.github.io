# ReCOVer System

ReCOVer is a four-step way to plan and write an essay, especially under exam time, and the steps are Recall, Chunk, Order and Verbalise. The writer decides what to say and in what order before writing any sentences, where most writers try to do both at the same time. An essay planned this way is quicker to write, and each problem in it can be traced to the step that caused it.

## Takeaways

- Plan the flow of ideas before writing any sentences.
- Recall the points, cut to a few groups, order them, write.
- Most essays need three or four main points.
- A messy plan almost always gives a messy essay.
- Each writing problem points back to a single step.
- Most essay trouble is a gap in knowledge of the topic.

## The four steps

Writing well needs two separate skills, knowing what to say and how the points connect, and turning that into clear sentences. Many writers try to use both at once and end up working out the structure in the middle of a sentence. ReCOVer does the structure first, in the three planning steps Recall, Chunk and Order, and leaves the sentences to Verbalise. The timings below are a guide for a typical timed essay.

```
Recall     every relevant point        up to 10 min
  |
Chunk      cut to 3-4 main groups      up to 5 min
  |
Order      intro, point 1, 2, 3        up to 5 min
  |
Verbalise  bullets into sentences      the rest
```

- Recall: list everything relevant to the question.
  - Arrange the points into a rough flow of main ideas.
  - Let the question decide which groupings matter.
- Chunk: cut the weak or off-topic points.
  - Keep a flow that moves in one direction.
  - Put supporting points under each main group.
- Order: write the outline in the order the essay will follow.
  - The introduction names the main points and how they connect.
  - Each main point then gets its supporting points and examples.
- Verbalise: turn the outline into sentences and paragraphs.
  - With many points, write bullets first, then sentences.

## Where it goes wrong

Each step fails in its own way, so the symptom in the finished essay shows which step to fix. When recall is hard in the exam, the topic was learned too shallowly beforehand. When the plan looks messy, the essay comes out worse and takes longer to write. Trouble with the sentences counts as a writing problem only when the plan was clear.

| Problem felt | Likely cause |
| --- | --- |
| Not enough evidence, padding | Recall, shallow learning |
| Points do not support the conclusion | Chunking |
| No sense of where the essay is going | Ordering |
| Sentences do not flow, plan was fine | Language skill |

- Test the knowledge first by explaining the points out loud.
- If that fails, study the topic again before practising the writing.
- Longer pieces use more main groups and more points per group.

## Why it works

Research on writing finds that an outline made before drafting reduces pauses during writing and raises rated quality for many writers. Beginners tend to handle content, structure and sentences in one pass, and experienced writers separate them. ReCOVer builds that separation into the process. The planning steps work best on a topic that was learned as a connected map, because the map already holds the groups and links the outline needs.
