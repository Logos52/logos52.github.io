# Prestudy

Prestudy is a short pass over a topic before the main lesson, lecture or study session, done to find the main ideas and how they fit together. Classes deliver new material quickly, and a learner who arrives with no frame for it spends the class overloaded and falls further behind each week. A learner who has done prestudy spends the class filling in details on a structure that already exists.

## Takeaways

- Prestudy organises a topic, and learning the content comes later.
- Find the main groups of ideas and how they relate.
- Memorise nothing yet, and skip the small details.
- Rough groups are fine, and they will change.
- A few minutes before a class still helps.
- A source that overwhelms is a signal to read something simpler first.

## How it works

The brain keeps information that has meaning and a place to go, and lets go of information that looks random. A learner who meets a topic cold has to make sense of everything at once in the class itself, which overloads working memory and makes the material easier to forget. Prestudy settles the big questions first: what the topic is, what its main parts are and how they connect. That splits the work of understanding over two sessions, so the main session can go to the details.

```
no prestudy:    class = big picture + details
                -> overload, most of it lost

prestudy:       short pass = big picture
                class      = details
```

- Each new detail then has a place to fit.
- Learning details before the frame keeps each fact isolated.

## How to do it

Grouping ideas together is called chunking, and it is the main work of prestudy. The pass should be quick and shallow on purpose. A prestudy that runs long is usually a sign that the learner has slipped into reading for detail. The groups stay as guesses, to be tested in the main session.

- Skim the headings, diagrams, bold words, terms and learning goals.
- Write those words down briefly as keywords.
- For an unfamiliar term, read only enough to know what it means.
- Group the keywords in whatever way makes sense.
- Note guesses about how the groups relate.
- Put it on a mindmap where possible, since lines can show relations.

Prestudy can happen at any time before the main event. Some learners do the coming week on the weekend before it, others do the day's topics that morning, and each pass should cover a whole topic even when the next lecture covers only part of it.

## How to tell it worked

A good prestudy leaves the learner ready for detail. It also leaves them with no details learned. Each sign of a good prestudy is about how the topic is arranged in the learner's head.

- The big picture of the topic is clear.
- The whole topic or subtopic was covered.
- No details or facts have been memorised yet.
- The main ideas are grouped and their links are visible.
- There are guesses about how the concepts relate.
- It feels possible to take in more detail now.

## Dense and multiple sources

Research papers and advanced textbooks can feel unreadable on first contact. That feeling means the reader does not yet have the background the source assumes. Start with the simplest material and move to denser material as the frame grows.

- Order sources from easy to dense: images, encyclopedia, textbook, papers.
- An image search gives a quick picture of an unfamiliar term.
- Keep one keyword list across all the open sources.
- Fill the main gaps before going deep on any one branch.
- Drop details such as single experiments until the frame holds.

Reading several authors to answer questions the learner set is called syntopical reading. It uses the same moves as prestudy across a set of sources in place of one.
