# Exit Strategy For Objects

An exit strategy is a decided way for an object to leave: used up, returned, sold, given away, or discarded. The exit is decided before the object is allowed to stay. When the decided exit is a sale, the sale gets a deadline of two weeks. The deadline holds even when the money is small. Without it, an owner keeps waiting for a small amount of money, and a chair meant to be sold spends a month in the hallway.

Deciding the exit at purchase time lowers four things later: hesitation, delay in selling, storage, and guilt at the time of removal. All four drop because the path out was decided at the same time as the decision to let the object in.

## Core takeaways

- Decide how an object will leave before you let it in. The ways out are: use it up, return it, sell it, give it away, or discard it.
- A plan to sell gets a deadline of two weeks, even when the money is small.
- Waiting for a small amount of money is the reason an object meant for sale stays for weeks.
- Sell when people want the object and it can leave fast. Give it away or discard it when the work of selling would keep it in the house.
- Before buying, ask six questions about how the object will leave. For things used rarely, rent or borrow instead of buying.
- An object that is large, awkward, or hard to sell costs a lot to remove, so a cheap purchase can end up expensive.

## The ways an object can leave

The common exits are: use it up; send it back; sell it; give it away; recycle it; discard it; rent instead of buying; borrow or share; use a city service instead of owning, such as a library, a tool library, or municipal bulky-waste collection. The best exit removes the object with the least unnecessary work while keeping the values that matter.

## When selling works and when it does not

Selling works when demand is real, the object's value is clear, and the logistics stay manageable. Selling fails when the object sits for weeks because the owner is still waiting for a small amount of money. That waiting is the reason the object stays.

The rule has two lines. Sell when demand is real and removal stays fast. Give away or discard when the work of selling would keep the object in the house. Discarding is the correct exit when the cost has already been paid and selling would create more work than value.

## Six questions to ask before buying

Before buying, ask six questions:

- How will this leave?
- Will it be used up?
- Can it be resold easily?
- Can it be rented or borrowed instead?
- Will it create storage or maintenance debt?
- What rule says when it comes out?

These questions make shopping a designed decision. [[wiki/Decision Making/Decision Making|Decision Making]] covers the same decision, with the exit chosen before the object enters.

## What removal adds to the cost of owning

[[wiki/Minimalism/Ownership Cost|Ownership Cost]] lists seven costs of owning an object, and exit cost is one of the seven. Large, awkward, low-demand objects account for most of that cost. A cheap purchase becomes expensive when it is difficult to remove.

## Objects you already own

For an object already in the house, the steps are: choose the cleanest exit; set a short deadline; stop trying to get the best resale price when speed matters more; think about why the object failed. The short deadline is the step that changes what happens the next time a week goes to a garage sale. [[wiki/Minimalism/Product Reduction|Product Reduction]] is the pass through the house that uses these exits. Delay in selling is a named failure on that page, and the deadline is the repair for it.

## Objects you have not bought yet

For objects not yet bought: name the exit before buying; prefer renting or a shared service for items used rarely; skip any purchase whose removal path is unclear.

## After the object is gone

Once the object has left, two questions remain. Why did this object fail? What buying rule changes now? Getting the object out fast matters more than the small amount of money a sale might have recovered.

## How to practice this

1. Before your next purchase, ask the six questions above, starting with how the object will leave. Notice whether any question has no answer. An object with no clear removal path is one to skip.
2. If the object would be used rarely, look for a rental, a shared service, a library, or a tool library first. Notice whether the need can be met without owning anything.
3. For each object you decide to sell, set a two-week deadline on the day you list it. Notice when the deadline passes with the object still in the house. That is the point to give it away or discard it.
4. Pick one object you already own and want gone. Choose the cleanest exit and set a short deadline. Notice whether you are holding it for a small amount of money; if so, choose speed over the money.
5. After the object is gone, write down why it failed and what buying rule changes now. Notice which of the six questions the object would have failed.
6. When comparing prices before buying, add the cost of removal. Notice whether the object is large, awkward, or low in demand; those are the ones that cost the most to remove.
