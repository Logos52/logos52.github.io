# Minimalism, Condensed

Minimalism, in the sense used here, means designing a home so that objects come in rarely, stay only while they do a job and leave easily. The design cuts the running costs of owning things and keeps the right objects in view.

## Takeaways

- Check why you want an object before buying it.
- Plan how an object will leave before it comes in.
- Every object costs space, upkeep and attention after purchase.
- Measure what you own by the space it fills, never by count.
- Keep spare room so a new need has somewhere to go.
- Change the surroundings instead of resisting urges.
- Reduce by category, largest costs first, in one focused pass.

## How it works

An object moves through a home in four stages: wanting it, buying it, keeping it and letting it go. Each stage has its own control, used at that point. A clear-out goes over the objects already kept, and a house move is a good moment for one.

```
want -> buy -> keep -> leave
  |      |       |       |
motive  exit    cost   deadline
check   plan    count  to sell
```

- Before buying: ask what the object is meant to prove.
- At purchase: pick the exit, such as resale, gift or disposal.
- While owned: count space, upkeep, attention and decisions.
- In a clear-out: gather a category, rank by cost, decide.
- On exit: sell within a deadline, else give or discard.
- Moving house resets habits and suits a clear-out.
