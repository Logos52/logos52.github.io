# Technique Training & Fundamentals

> Not yet reviewed by Wedge.

Technique training and fundamentals are the base study methods that later, harder work is built on. Four bundles make up that base. Inquiry-based learning has you create questions and answer them, so curiosity steers what you read. Mind mapping turns linear material into a picture of relationships that breaks the false sense of fluency ordinary notes give. Importance-based chunking sorts information according to why it matters. The retrieval methods then bring knowledge back at widening intervals and in layered passes, so gaps show up while there is still time to fill them. The target is a level of skill where you use each method correctly without coaching yourself through it, and a new method waits until the current ones reach that level.

Asking before reading is the first bundle. [[wiki/Dimensions/Deep Processing/Inquiry-Based Learning|Inquiry-Based Learning]] means creating problems and then answering them. Each answer raises more questions, and that cycle builds a richer and more usable understanding with stronger retention.

Asking questions only helps if the answers land somewhere, which is where the second bundle comes in. [[wiki/Dimensions/Deep Processing/Mindmaps|Mindmaps]] turn linear material into a nonlinear picture of relationships, and an early map should look messy. New knowledge only settles once it joins a schema, a web of related knowledge.

How you group what you map decides how efficient it becomes. [[wiki/Dimensions/Deep Processing/Importance-Based Chunking|Importance-Based Chunking]] judges each group by why it matters, looking past the first obvious reason to a broader root reason.

Encoding still leaves some decay, so the fourth bundle covers retrieval. [[wiki/Dimensions/Retrieval/Spaced Interleaved Retrieval|Spaced Interleaved Retrieval]] brings answers back from memory at intervals that keep widening, approaching them from a new angle each time. The [[wiki/Dimensions/Retrieval/Multipass System|Multipass System]] covers a large topic in layered sweeps, starting with logic and concepts before details. [[wiki/Dimensions/Retrieval/Revision|Revision]] goes back to studied material to locate gaps and close them through true recall, meaning you can use the knowledge with no cue present.

All four bundles serve the five capabilities set out on [[wiki/Dimensions/Dimensions of Learning|Dimensions of Learning]], and the skill target for each one comes from [[wiki/Concepts/Four Stages of Competence|Four Stages of Competence]]. At the stage called conscious competence you can use a method correctly if you apply effort. The goal is to move each method toward the top of that stage, where success is common and cheap, before adding the next one. [[wiki/Techniques/Techniques - Learning Craft|Techniques - Learning Craft]] is the parent hub that groups the working methods by the part of learning each one trains.
