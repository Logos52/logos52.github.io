# Diagnosing a Character

Diagnosing a character means running a written character against a fixed list of checks to find why they feel thin or interchangeable. This desk keeps a checklist for the job. The list grades how the character is built on the page, and it says nothing about whether the character is a good person.

## Takeaways

- The checklist grades the build of a character.
- Check every character against the full cast, never alone.
- Two characters with near-identical traits is a cast problem.
- The most common result is a character well built but thin.
- A round character needs one contradiction, shown before it is named.
- If readers need name tags to follow dialogue, fix the voice.

## How to use it

A diagnosis starts with the character on their own and then sets them beside everyone else in the story, because most faults only show up in comparison. Each check below names what a well-built character has. Each check also has a page of its own that explains the craft behind it, cites the sources, and describes the fix when the check fails.

- Relations: the links to other characters are built into the story.
- Distinctness: no other character shares the same defining trait.
- Arc: this character's type of change makes sense beside the others.
- Contradiction: the character shows one before anyone names it.
- Voice: a reader can tell them apart without name tags.
