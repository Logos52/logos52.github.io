# Story Craft, Condensed

Story craft is the set of working rules writers use to build characters, plot and scenes that hold an audience. A writer who has the core rules can start a story before reading the full page on each one.

## Core takeaways

- A character starts from a wound, false belief, want and need.
- The arc is the distance from the false belief to the truth.
- Every scene turns a value, from better to worse or the reverse.
- Link events with "but" or "therefore", never with "and then".
- Seed every big payoff well before it arrives.
- Show feeling through objects and actions, instead of naming it.
- Give each lead a turn at the centre, on a schedule.

## How it works

A story runs on cause and effect between what the characters want and what the world gives back. The character's want drives the plot, and the need, which the character often cannot see, decides the ending. Each scene changes something the character values, and each change causes the next scene. Details planted early come back later, and the audience recognises them, which makes the ending feel earned.

- Wound: a past event that taught a false belief.
- False belief: drives the want, blocks the need.
- Scenes: each one turns a value and causes the next.
  - Midpoint: the character glimpses the truth.
  - Low point: the false belief costs the most.
  - Climax: the character acts on the truth, or refuses it.
- Seeds and payoffs tie the early story to the late one.

```
wound -> false belief -> want -> scenes turn values
                                     |
          low point <- belief costs more each time
              |
          climax: act on truth (change) or refuse (fall)
```
