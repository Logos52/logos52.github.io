# The Character Web

A character web is a cast designed as a set, where each character is defined by how they differ from the others. John Truby's rule in The Anatomy of Story is that no character is designed alone. A writer who builds the cast this way gets characters who each stand for a different answer to one question the story asks, and that spread of answers is where a story's moral complexity comes from.

## Takeaways

- Design every character against the others in the cast.
- Hero against villain alone gives a flat, two-sided story.
- Four positions on one question is the minimum for complexity.
- Each position is a different answer to the same moral question.
- Only a character who can surprise should hold a position.

## How it works

The story asks one question, and the writer states it in a single sentence. Robert McKee calls that sentence the controlling idea, a value joined to a cause. The web splits the question into several answers and gives each answer to a character, so every scene between two characters tests one answer against another. When only two answers exist, the hero's and the villain's, the story can only say that one of them is right.

- Write the story's question as one sentence first.
- Find four distinct answers to it.
- Give each answer to one character.
- Each character opposes each of the others in some way.
- A scene between two characters sets two answers against each other.

```
            the one question
         /     |       |     \
     hero   opponent  ally   second opponent
    answer   answer   answer    answer
     each answer pushes against the others
```

## The four corners

Truby's floor for complexity is four-corner opposition: the hero, the main opponent, and two more characters who oppose both of them and each other. Each corner holds a fixed reading of the question, and the drama comes from the readings meeting. E. M. Forster's test for a round character helps decide who takes a corner. A round character can surprise in a convincing way, and a flat character cannot, so a flat character cannot carry a corner's answer through a whole story.

- The hero's answer: the answer the story tests hardest.
- The main opponent's answer: the strongest case against the hero.
- The two other corners: answers neither of the first two holds.
- Round characters carry corners, and flat characters fill scenes.
- Two characters with the same answer are one character written twice.

## Where it fails

The most common failure is the two-part opposition, where the whole cast lines up behind either the hero or the villain. Another failure is a cast list that drifts between planning notes, so two notes name different characters for the same four corners. The fix for both is to write the question and the four answers down once and check every later note against that list.

- Every supporting character agrees with the hero or the villain.
- Two characters give the same answer under different names.
- The corners change between one planning note and the next.
