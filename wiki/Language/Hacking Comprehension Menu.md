# Hacking Comprehension Menu

The Hacking Comprehension Menu is a list of mid-session changes that keep real language on the screen when it has gone too hard to follow. The point is a useful difficulty range: hard enough to learn from, understandable enough to stay engaged with. A lever from the list replaces quitting, and it replaces pretending the session was useful.

## The menu

The rows stay as rows. Each one keeps the input and moves difficulty; none of them turns the session into a lesson about the language. Native language and language being learned are written in full here because the initials hide which channel is doing the work.

### Tool levers

| Lever | What it does |
|---|---|
| Matching target-language subtitles | A written line in the language being learned sits on the same audio, so the ear has something to parse against. |
| Popup dictionary | A word can be checked without leaving the video or the page. |
| Automatic pausing | Each line gets more time before the next one arrives. |
| Blurred native-language translation | A confirmation is available without a full, clear translation taking the work. |
| Metalayers | Lookup, replay, subtitles, and navigation sit in one environment. [[wiki/Language/Immersion Metalayers\|Immersion Metalayers]] is the tool-lever sibling, including how a clear translation becomes the failure mode the blurred row is there to prevent. |

### Technique levers

| Lever | What it does |
|---|---|
| Priming | A short dose of words, sounds, characters, or grammar before the session, so the session is less opaque. [[wiki/Language/Preparation\|Preparation]] is the priming lever in full. |
| Reduce speed | The audio slows enough to process while it still sounds like the language — a little slower, not until the signal becomes something else. |
| Rewind | Another pass at the same audio or subtitle line. |
| Lookups | A word, a sentence, or a grammar point, when that lookup can unlock meaning. |
| Spoil the plot | A summary first, so context carries more of the meaning. |

### Content levers

| Lever | What it does |
|---|---|
| Reuse known content | Something already seen in the native language, or already studied interactively, run again. |
| Known topics | Content about a domain already understood. |
| Simple or simplified content | Four different kinds: learner material, children's content, simple plots, or beginner-friendly native content. Learner material is not the same thing as children's native speech. |
| Visual content | Acting, diagrams, images, demonstrations, or other obvious context — a lot of the meaning arriving without words. |

[[wiki/Language/Interactive Immersion|Interactive Immersion]] is the mode this menu is usually used inside.

## One variable

This is a [[wiki/Dimensions/Self-Regulation|Self-Regulation]] tool for language learning: the thing reached for when a session is failing. The first move is one variable, not a stack.

The six candidates, collapsed from the tables above:

1. Easier content.
2. More tool support.
3. More preparation.
4. A shorter session.
5. More visual context.
6. A different content domain.

Changing everything at once leaves no way to tell what helped. [[wiki/Dimensions/Mindset/Marginal Gains|Marginal Gains]] is the same discipline at smaller grain: one small thing, then a look at whether it moved.

The case against the menu is the same case against any lever list. Minutes spent choosing and stacking tools are minutes not spent on input. Spoiling the plot costs the surprise that may have been the reason for sitting down. Slowing until the audio stops sounding like the language trains a different signal. After three levers, if gist is still gone, the content is the variable — switch content, do not add a fourth tool.

The checkable expectation is local. Gist returns after one change, or it does not, and the next move is already named.

Once gist is back, [[wiki/Language/Freeflow Immersion|Freeflow Immersion]] is the mode the session returns to.

A session that used the menu ends in one of two places. Gist came back after one change, or three levers failed and the content was the thing that had to move. Either way the input stayed, and a lesson about the language did not replace it.
