# Grammar primers

A grammar primer is a short, incomplete orientation to common patterns that orients attention in real input instead of serving as a production rulebook. Common patterns become easier to notice and understand once they have been seen once, in plain language, with examples. Grammar still earns that keep: explicit knowledge is useful for noticing and monitoring, not as the engine that produces speech.

## The loop

The loop sits inside [[wiki/Language/Preparation|Preparation]], deliberate priming that makes future input easier to follow. A small base comes first: some time already spent attending to the language, a handful of words, basic script or sound orientation, and a lookup tool. Then one short section is read without any attempt to master it. Immersion resumes. The pattern is hunted in real speech or text — [[wiki/Language/Noticing Game|Noticing Game]] is how the primed pattern gets hunted in input. The sketch is re-read as hours accumulate, not on a measured interval. A fuller reference opens only when this one has become familiar and still cannot answer the question input just raised.

## What it does and refuses

A working primer explains common patterns in ordinary words and leads with the language's hardest-to-miss difference — verbs in one language, the predicate in another, nouns in a third. Examples make the pattern recognizable. Production pressure stays low: the pass maps form to meaning in input, and it does not require producing the form. The same loop is the should-list's other half. The sketch is not comprehensive, does not demand memorization, and does not become a translation-rule manual — [[wiki/Language/Language Isn't Math|Language Isn't Math]] owns the claim that grammar is not a complete generator. It does not replace immersion. A primer that stalls input until grammar is "finished" has inverted its job.

A reusable outline, not a branded template: recommended knowledge; mindset; how to use; core primer; quick reference; what to do after. The [[wiki/Language/Vietnamese Grammar Primer|Vietnamese Grammar Primer]] is the language-specific instance of this outline, rebuilt around Vietnamese rather than copied from another language.

[[wiki/Language/Hacking Comprehension Menu|Hacking Comprehension Menu]] is how to keep input in the zone where patterns stay visible. A short sketch will miss usages; a reader who wants a production grammar will feel cheated. The price is a few minutes of orientation that only pays if the next session hunts the pattern. The quit signal is a sketch being memorized, input postponed until the sketch is "done," or the same section re-read with no hunt. The checkable expectation: a primed pattern starts showing up in subtitles or speech within the next few sessions, still incomplete.

The same short guide, after the loop has run, is a door walked back through and left when input starts asking questions the sketch cannot answer.
