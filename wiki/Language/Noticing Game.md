# Noticing Game

The noticing game is a high-attention way to spend time in a language that may not yet be understood. Background listening or passive listening does not count, because without attention the time does no work.

What the learner looks for are handholds inside that barely understood stream. Those handholds are cognates, words already known, or words from a word list or bingo card. If those lists run out, the next place to look is priming, meaning earlier study done to raise comprehension during later immersion, or additional word lists.

The same search can follow the learner's other study. Once new words have been learned that day, the game can be pointed at those words. After a short stretch of grammar study done for the same reason, it can be pointed at a grammar pattern, looking for that pattern in the wild.

The game belongs to interactive immersion, the wider set of activities that use tools to go deeper into input. After a metalayer is set up, meaning a lookup-and-pause layer on top of a show, the game is played on dual-channel input. Dual-channel input is content the learner reads and hears at the same time.

Intensive reading goes further than that search alone. It also looks for two-target sentences and does lookups to get the meaning of each sentence. A two-target sentence, sometimes written 2T, is a sentence with two things the learner needs to look up to piece it through. If no such content can be found, the noticing game is the fallback. The two-target threshold is a reminder not to look up every single word.
