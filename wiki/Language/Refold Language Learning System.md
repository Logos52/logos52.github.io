# Refold Language Learning System

The lessons that teach this method cover the first two phases. Those phases are fundamentals, and reading plus listening. The two phases are similar. During fundamentals, the learner is still working on the earliest pieces of the language and making it stop sounding like noise. The reading-plus-listening phase is about gaining comprehension and picking up the first 5,000 words. That work is done by reading text, including books, captions, transcripts, and similar material, paired with audio whenever possible.

Those two phases still have to be spent in a useful mix of activities. Inside the same lessons, progress is a balance of three pillars. The pillars are preparation, interactive immersion, and freeflow. Preparation is learning about the language and priming for acquisition, meaning studying ahead of time so later immersion is easier to understand. Interactive immersion expands understanding through interactive experiences and tools. Freeflow turns conscious knowledge into subconscious abilities.

## How the course is meant to be used

Homework assignments are a baseline. If more time is available, do more than the assignment asks. The core of making progress is to spend time with the language. Extra time is best spent on activities where the learner is actively understanding the language, even if only a little.

The lessons give specific instructions, which removes as many decisions as possible. Some things will not work for everyone. The learner still has to make the choice or adaptation that fits their circumstances and learning style.

Someone who is not a total beginner should move through the first week quickly. A recap of the material within a day or two is still recommended. A whole week of review would be boring if the basics have already been learned elsewhere. The lessons were built as the first day through the thirtieth day, in sequence, and going slower is fine. Staying on the same day twice and repeating the homework is allowed. Some people go through the lessons twice. The first pass absorbs what it can. The second pass focuses on what did not make sense the first time.
