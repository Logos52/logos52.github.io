# Freeflow Immersion

Freeflow is relaxed but attentive time with real language already followable for gist, almost never pausing, rewinding, or looking things up. Attention is still required. Zero attention means the session does not count.

## When it is the mode

Exposure needs a lower-friction mode where attention stays alive without constant tool use. This mode converts conscious knowledge into faster instinct. It is one of three, held at [[wiki/Language/Three Pillars of Language Learning|Three Pillars of Language Learning]].

It fits when the gist already holds — the main events or point, without every sentence — and the content is interesting enough to hold attention. Less interrupting yields more minutes of input per hour, with no multiplier attached. It also fits when understanding without tools needs practice.

Two on-ramps. The default is content already used in [[wiki/Language/Interactive Immersion|Interactive Immersion]]. The second is a rewatch of something already seen in a native language — what a beginner with no interactive backlog can run today.

Good freeflow is high attention, low interruption, content close enough to enjoy, and a willingness to tolerate gaps. [[wiki/Language/Attention is Important|Attention is Important]] is the zero-attention rule this page depends on. If the gist holds and every sentence does not, keep going. That clause does not excuse a session where attention was elsewhere.

Short notes afterward: How much was understood? Was it interesting? Was it fun? Was focus possible?

## How it fails

Freeflow is not a replacement for interactive work, and it is always a high-attention activity. Three rows cover the ways the definition breaks.

| Failure | Signal | Repair |
|---|---|---|
| Passive exposure | The content played but attention was elsewhere | Shorten the session or choose better content. Improve selection before adding harder techniques. |
| Too difficult | The gist cannot be followed | [[wiki/Language/Hacking Comprehension Menu|Hacking Comprehension Menu]], or return to [[wiki/Language/Interactive Immersion|Interactive Immersion]]. |
| Over-tooling | Constant pausing and lookup | Label it interactive immersion instead. Relabel, don't guilt. |

Wrong mode when gist is gone. A ritual when attention is gone. Lookups are given up, which is the point. Gist still gone after one repair attempt: switch mode or content. The check is the four notes, especially whether focus was possible.

The mode is still relaxed and attentive. Zero attention still does not count. The harder mode is still there.
