# Immersion Metalayers

An immersion metalayer is a piece of software that sits on top of a video, show or text in the language you are learning and adds study controls to it. The usual controls look up a word when you hover over it, pause the video after each spoken line, jump between subtitle lines, and show a hidden translation on request. With them, content that is slightly too hard can be worked through line by line instead of given up on.

## Takeaways

- A metalayer adds lookup, pausing and translation to real content.
- Use it with audio and subtitles in the language you are learning.
- Keep the translation hidden until you want to check yourself.
- Automatic pausing gives you time to read each line.
- Do not look up every unknown word.
- Cap the setup time, then start watching.

## How to set one up

Most metalayers are browser extensions that work on video sites and streaming services. The setup takes a few minutes, and a few settings decide how useful the tool is. The subtitles should be in the language you are learning, so that you read and hear the same words. The translation into your own language should be hidden, because a visible translation gets read before you have tried to understand the line.

- Install the extension and reload the video page.
- Set the subtitle language to the language you are learning.
- Set the translation language to your own, and hide it.
- Turn on automatic pausing after each line.
- Hover over a word to look it up.
- Hover over the hidden translation only to check a line.

## How to use it

The tool lets you stay inside the content while you work out what it says. A line plays, the video pauses, and you try to understand the line from what you know, then look up the one or two words that block you. Working this way is slow, and ten minutes of study may cover two minutes of video. Because a session covers so little, the same content is worth watching again later without tools.

- Try the line first, then look up what blocks you.
- Skip a line with many unknowns and move on.
- Use an audio dictionary for a word you cannot pronounce.
- Learning Chinese: check the subtitles use the script you are learning.

Simplified and Traditional Chinese write many common characters differently, so subtitles in the other script teach forms you are not learning.

## Where it fails

The tools make three bad habits easy. Reading the translation first turns a language session into watching a show with subtitles in your own language. Looking up every word stops the content and leaves little time for listening. Setting up and adjusting the tool can take over the session, so give the setup a fixed number of minutes and then start.

- The translation shown by default.
- A lookup for every unknown word.
- Setup and settings taking up the study time.
