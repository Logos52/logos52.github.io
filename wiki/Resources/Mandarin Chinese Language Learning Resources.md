# Mandarin Chinese Language Learning Resources

Pronunciation, character recognition, and immersion stay on separate tracks, linked rather than piled into one feed. Start with beginner input you mostly already understand, and with sound. This list is a personal shelf, not a syllabus.

## How this list is used

**Comprehensible input** is speech or text you mostly already understand. Start there, with pinyin and sound, before character tools. Track **simplified versus traditional** on every immersion row — the two Chinese script standards. Once beginner input is stable, harder channels, subscription video, and podcasts build tolerance for ambiguity. Character-specific tools wait until pronunciation orientation is underway; the entry orientation lives on [[wiki/Language/Character Primer|Character Primer]].

Links and brief notes are the value. Categories here are jobs, not a calendar. TeaTime Chinese and the two Mandarin Corner slow-intermediate playlists are marked TOP as a personal ranking, not a law. A spaced-repetition deck is an optional class, not a requirement. Previously watched content you already care about is a valid source.

Gated cheat sheets, week-reflection templates, habit-tracker apps, graduation surveys, redacted primers, and testimonials are not resources a stranger can use. They are not listed.

## The list, by job

**Soft subs** are toggleable captions. **Hard subs** are burned into the video. A **metalayer** is a subtitle or popup layer on top of real video. **3-channel** means audio plus target-language captions plus native-language captions. A **seeder playlist** is a starter list used to train a recommendation feed.

## What becomes daily

Which of these become daily immersion defaults after testing? Which should be tagged beginner, bridge, native, or stretch once they have been used?

A personal harvest rots. Gated doors pretend to be resources. A catalog invites collecting instead of watching. Time spent choosing is time not spent on input. If nothing on the list becomes daily, the list is not the lever. The check is a script tag on every immersion row, and something used this week.
