# Validity and Truth

# Validity and Truth

An argument can fail in two places: a starting fact can be false, or the conclusion can fail to follow from the facts. The argument pages under Worldviews & the Political Order test the second. A reader who can see where a conclusion stops following can check a political argument without first settling every disputed number in it.

## Takeaways

- A conclusion can follow from false facts.
- It can also fail to follow from true ones.
- A starting fact stands unless something a reader can check overturns it.
- A correct number can still support nothing.
- Most failures fit one of eight named breaks.
- State the other side so its holder would accept the wording.
- A failed argument does not make its conclusion false.

## How it works

Stephen Toulmin's model splits an argument into three parts. The claim is the conclusion, the grounds are the facts offered for it, and the warrant is the assumption, usually unstated, that lets a reader step from the grounds to the claim. Most political arguments break at the warrant, so a check looks there first. Disputing every fact at once leaves no way to see whether the steps between the facts hold.

- Take the facts as given unless a checkable source overturns them.
- The burden falls on whoever wants a fact removed.
- A statistic on these pages is a fact inside an argument.
- Whether it is accurate is one question.
- Whether it licenses the conclusion is another.

```
grounds  --(warrant)-->  claim
   |                       |
true or false        follows or not
```

## Eight ways a conclusion stops following

Each break has a name so that it can be spotted again. On the argument pages the break is written out in full, so the reader sees it happen and does not take a label on trust. The last one on the list limits how far a claim reaches and does not refute it.

| Break | What happens |
| --- | --- |
| Contradiction in a definition | One word must carry two incompatible meanings |
| Equivocation | A word shifts meaning between fact and conclusion |
| Missing precondition | A general result used where its conditions are absent |
| Correlation as cause | Two things occur together, one is called the cause |
| Category error | A question answered with a method built for another kind |
| Begging the question | A fact assumes what the conclusion asserts |
| Reversibility | The same form works equally against its user |
| Historical counterexample | One case where things went otherwise |

## Rules for an argument page

An argument page states the other side at full strength before answering it. The oldest form of this is the medieval article used in Thomas Aquinas's Summa Theologiae, which put the objections first, and each objection had to be a sound argument from a recognised authority. Anatol Rapoport's rule, as set out by Daniel Dennett in 2013, sets the standard for stating the other side: the holder of the position should thank the writer for the phrasing.

- Narrow the claim before defending it, never after.
- Concede what the facts earn, and nothing more.
- Use a worked case with real quantities.
- Say exactly what the argument establishes.

## What a check can settle

A check can show that an argument works, or show the step where it breaks. It cannot show that a position is false, because a bad argument for a true claim leaves the claim where it was. What it gives in return is a result that anyone who can follow the steps can check, with no need to trust a source or a side. An argument made for a selfish motive is not false because of the motive.

## Sources

The claim, grounds, and warrant analysis is Stephen Toulmin, *The Uses of Argument* (1958). The warrant is the usually unstated assumption licensing the step from one to the other. The standard for stating an opposing position is Rapoport's rules as set out by Daniel Dennett in *Intuition Pumps and Other Tools for Thinking* (2013): re-express the target's position so clearly and fairly that they would thank you for the phrasing. The objections-first form is the medieval *articulus*, most fully worked in the *Summa Theologiae*, where producing the objections was the students' task and each had to be a valid argument resting on a recognized authority.
