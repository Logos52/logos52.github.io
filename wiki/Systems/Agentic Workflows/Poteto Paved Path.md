# Poteto Paved Path

How do you trust an agent more?

Trust is how many agents you can leave alone. A harder prompt does not raise it. The next agent opens the files and extends the pattern already there. The codebase is the memory.

Verification for correctness. A feature map says what exists and how a person reaches it. A command runs the real app and saves the proof. Until those exist, you are the check.

High quality skills, for example pstack. The procedure lives in the repo. The agent can still skip it. You do not install pstack to copy a pull-request count.

Refactor the architecture so it is agent friendly. Agents like the shortcut, so the shortcut has to be the correct edit.

Greenfield is a new program. No walls yet. The short edit becomes the structure. Grok Bot started there. Dune is what it runs on now. One folder, one job. A bad comment fails the build. A bad import fails the build.

Brownfield is a program that already has walls. A new person cannot delete the live database. An agent that copies the files stays inside them. You add a wall where agents still fall through.

Gardener. The spread is weeds. You call it mold. Delete tech debt. Keep one paved path. Lint against anti-patterns. Catch the mold while it is one patch.

## Whenever you correct your agent

1. Codebase
2. Static analysis (lint/compiler/ci)
3. Rules/bugbot
4. Skills
5. "Style guide"

Put the correction as high as it can go. A harder prompt is the style guide.

## Your code, and this wiki

The files you accept are the memory. A shortcut you leave is the pattern the next edit copies.

Accepted wiki pages, and the two checks, are the brownfield. `scripts/holdings.py` rejects a sentence that points at something the page never named. `scripts/source-words-check.py` rejects a sentence that points at where the words came from. A page you have not named is the greenfield. You name it. You open it. You read it. A bad sentence left in place is mold.

## Building a Michelin kitchen

A Michelin kitchen, not a software factory. You still answer for the plate. You are no longer cooking each part.

Grok Bot is the line cook. It watches Slack, Sentry, Datadog, and PlanetScale, and starts the next station.

Cloud agents are a separate computer. They open a pull request after the laptop is closed.

Automations and the Agent SDK are the team. They start from events.

You are not in that kitchen on this wiki yet. You still open the page. A helper does not merge. You merge.
