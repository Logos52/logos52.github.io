# ICS Program Map

A stage-ordered path through the ICS program, linking the wiki notes that cover each stage. This is a
**view** over the theme-organized wiki (Dimensions, Self-Management, etc.) following the program's own
Kickstart → High-yield → Growth sequence. Source corpus lives privately in `raw/private/ICS` (not linked
here); this map points to distilled wiki notes only.
