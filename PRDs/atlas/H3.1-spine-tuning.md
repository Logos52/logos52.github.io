# H3.1 — Spine graph: defect fix + constellation pass

Wedge reviewed the first render: not accepted. The mockup aesthetic is now the **reference standard** — sparse constellation in a horizontal band, six labeled landmarks, tiny satellites, very few lines, generous dark space. The current render fails it for two reasons: a slug defect and link density. Fix in this order.

## 1. Defect: SPINE_HUBS never matched

`SPINE_HUBS` in `HomeLanding.tsx` uses raw vault paths; the build slugifies them. Zero hubs matched, so no pinning, sizing, or labels applied. Replace with the **built** slugs (verified against `public/static/contentIndex.json`):

```ts
const SPINE_HUBS = [
  "wiki/Syntheses/First-Principles-of-ICS",
  "wiki/Systems/AI--and--Agentic-Systems/Agentic-Engineering",
  "wiki/Self-Management/Focus-Management---How-to-Enter--and--Recover-Inside-a-Work-Block",
  "wiki/Minimalism/Minimalism-as-Systems-Design",
  "wiki/Red-Team/Red-Teaming",
  "wiki/Language/Refold-Language-Learning-System",
]
```

Add a build-time guard: if any hub slug is absent from the content index, `console.warn` listing the misses — this failure mode must never be silent again.

## 2. Selection: scarcity is the aesthetic

- Node set = the 6 hubs + up to **3 satellites per hub** (its highest-degree direct neighbors within `wiki/`), global cap 24. Mobile: hubs + 1 satellite each.
- Drop degree-ranked global selection entirely — it let one domain flood the map.

## 3. Link filtering: this is what kills the blob

- Render **only links with a hub endpoint**. No satellite↔satellite links.
- Cap rendered links per hub to its 6 strongest. Target total on screen: ≤ 30 lines.
- Link style: 1px, low opacity (existing `#3a3640`-equivalent token).

## 4. Forces (starting values for this round)

- Hubs: pinned to their domain anchor x (fx), free y within the band.
- Satellites: `forceX(parent hub x).strength(0.3)`, `forceY(centerline).strength(0.15)`.
- `forceManyBody().strength(-200)`, `forceLink.distance(60)`, `forceCollide(r + 14)`.
- After settle (~1s), zoom-to-fit with 40px padding — the render must fill the canvas width; the current dead margins are unacceptable.

## 5. Labels and size

- Hubs: radius ×1.8, mono 10px label always visible, domain-tinted light (node color mixed ~70% toward white).
- Satellites: radius 3–4px, no label until hover.

## Acceptance

- Six labeled landmarks spread across the full canvas width, left→right in the domain order; satellites cluster tightly around their hub; ≤30 visible lines; no node ball anywhere; pulse rings still render.
- A missing hub slug prints a build warning.
- Screenshot back to Wedge before commit is finalized — he is the acceptance gate for this one.
- Commit: `atlas(H3.1): hub slug fix, constellation selection + link filtering`.
