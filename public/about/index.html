How this wiki works

LLM agents compile source material into linked notes, and a scheduled health check keeps them accurate.

This site, llm-knowledge-base, is a public knowledge base kept by LLM agents. It turns source material into durable notes that link to each other, and each pass makes the base a little more useful. It is also an ongoing experiment in using LLM agents to maintain a knowledge base over time.

Raw sources are compiled into pages, then cross-linked so the graph stays easy to navigate. LLM agents do much of the compilation, health-checking, and synthesis.

A health check1 runs over the whole wiki on a schedule, looking for stale pages, missing links, and claims without a source. It is how the pages stay honest after the first draft, and why old pages can change without anyone asking.

1 The dashed loop in Figure 1 is the lint: a scheduled pass over stale pages, missing links, and claims without a source.

From the reader’s point of view, a source is saved, summarised, and drafted, then it waits for a decision. It is approved, or changes are asked for. Later, a new source may disagree2, and the page is drafted again; or a newer page replaces it, and the old one is archived.

2 The usual path is blue. Dashed lines go back: when changes are asked for, or when a new source disagrees.

Treating the knowledge base as the primary surface — the place where daily thinking happens — is what kept it in use. Writing durable pages worked better than working out the same answers again. Making pages public by default made the writing clearer. The lesson is to build up pages that get reused3. The pipeline exists to turn raw input into pages that can answer future questions.

3 The value is in pages that get reused and revised. A pile of captured sources does not have that value by itself.

The base supports a person’s thinking and does not replace it. The open problem is how a person keeps thinking actively while the knowledge base gets more useful.
