It is not a third-party masonry/isotope/packery/muuri/macy/colcade/imagesLoaded library (no matches for those names in first-party scripts).
The script is https://www.ndc.co.jp/_astro/Wrapper.astro_astro_type_script_index_0_lang.ChRMvoj-.js
On this page it runs the function minified as hx, registered via xR when the path is the whiteboard index (called from yR on load, and again on swup:page:view). The function reads getComputedStyle(container).gridTemplateColumns to get the column count, then absolutely positions each card in the shortest column and sets the container height. It also listens for window resize.
