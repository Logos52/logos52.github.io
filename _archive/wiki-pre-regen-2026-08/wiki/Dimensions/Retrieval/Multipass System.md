# Multipass System

A Multipass System involves going through material multiple times with different purposes on each pass. This is especially useful for dense or high-stakes material where a single pass is insufficient for deep understanding and retention.

## Typical Passes

1. **Overview Pass** — Skim for structure, main ideas, and overall shape.
2. **Relationship Pass** — Focus on connections, dependencies, and how pieces fit together (often using Aim-style questioning).
3. **Detail Pass** — Deep encoding of specific content with active note-taking.
4. **Application / Retrieval Pass** — Test understanding through problems, teaching, or retrieval practice.

## When to Use

- Dense textbooks or technical documents
- High-stakes exam preparation
- Learning complex systems where relationships matter as much as facts

## Integration

Multipass works well alongside Spaced Interleaved Retrieval and the Bear Hunter System. The different passes can be scheduled across days to leverage spacing.
