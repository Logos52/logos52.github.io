# Tasks

> **Frontmatter:** `type: task`, `status` (Incomplete / Complete), `priority` (important + not urgent / important + urgent / not important + urgent), `do-date`, `time-taken`, `break-length`.

> [!tip] Automations (plugin-free — see `scripts/`)
> - **✅ task complete → break timing**: `node scripts/complete-task.mjs "Tasks/Task 1.md" 50`.
> - **Recurring tasks** (weekly eval + goal tracking, Priority 0 check-in, Skills audit) live here as task notes — duplicate one each cycle, or schedule a copy via cron/launchd.
