# Kolbs

> A Kolb's reflective cycle: Experience → Reflection → Abstraction → Experimentation.
> **Frontmatter:** `type: kolbs`, `status` (Not started / In progress / Done), `start`, `finish`, `mgs-and-experiments`. Links: `next-kolbs`, `previous-kolbs` (self), `skills`.

> [!tip] The ☑️ cycle button (plugin-free)
> `node scripts/new-kolbs.mjs "Kolbs/SIR 1.md"` — sets the current Kolbs to `Done`, creates the next from [[Kolbs Template]], links `previous-kolbs`/`next-kolbs`, and prints the path to open.
