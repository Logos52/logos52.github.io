# L3 — Raw Agent First-Pass Synthesis

This folder contains **L3** material: the agent's initial synthesis / draft output before any voice polishing or significant human editing.

## Purpose
- First-pass structured notes, summaries, or drafts generated by Hermes (or other agents) from raw L4 source material.
- These are typically unpolished, may contain attribution language, lower signal density, or inconsistent voice.
- The goal is to get raw thinking out of the agent's head and into a reviewable artifact.

## Naming Convention
Files should follow this pattern:

`YYYY-MM-DD-Short-Descriptive-Name-L3.md`

Examples:
- `2026-05-22-Agent-Memory-GBrain-and-Lossless-L3.md`
- `2026-05-20-Self-Regulation-Hub-Audit-L3.md`

## Workflow
1. Raw sources (L4) live in `raw/`.
2. Agent produces L3 drafts → written here by default.
3. L3 files are fed into the L3 → L2 voice converter (or `light-voice-evolution` skill) to produce polished L2 versions.

## Notes
- Do not put final wiki content here (use `wiki/` for L1).
- Do not put raw unprocessed transcripts or clippings here (use `raw/`).
- Once an L3 file has been converted and reviewed, the polished version should move to `outputs/L2/`.

This tier exists to keep the pipeline clean between raw input and polished output.
