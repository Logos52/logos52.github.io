# Bear Hunter System - Skin Phase

The Skin phase is the evaluate and consolidate step that turns the working map from Aim and Shoot into a final, reliable chunk structure. After multiple cycles have clarified relationships, Skin creates the certainty and clean backbone required for retrieval.

## Refine the Map Into Final Structure

Skin is exclusively for judgment at the evaluate level:

- Consolidate and integrate what multiple passes have revealed.
- Rename vague chunks and merge or split as the true relationships dictate.
- Remove clutter and keep only high-value arrows.
- Make the main flow obvious.
- Convert the result into explicit retrieval prompts for SIR.

Do this the same day when possible. A dedicated weekly Skin pass works when daily refinement is not feasible.

## Handle Evaluation Pressures

The main pressure is attachment to early chunk labels and the accumulated detail from Shoot. Treat the current map as a hypothesis to be stress-tested against the best current understanding.

Use importance, function, contrast, and mechanism criteria (including GRINDE-style or intuitive chunking) to decide what stays. The checkpoint for the phase confirms you can reconstruct the refined structure from memory and point to exactly which relationships stabilised only after the Skin pass.

When vagueness persists, run another targeted Aim-Shoot cycle on the weak area instead of polishing a flawed structure.

## Integration Across the Climb

Skin completes each BHS cycle and produces the stable artifact that Camp I retrieval, Camp II reconstruction, and Summit execution all depend on. A well-skinned map compounds: every later session costs less time and yields higher quality.

Carry the final chunk structure and its retrieval prompts forward. They are the concrete output of the entire encoding climb for that topic.
