# Bear Hunter System - Shoot Phase

The Shoot phase is where you actively encode new information into the networks begun in Aim. It turns initial relationships into integrated, retrievable structure by placing details under the right chunks and refining connections in real time.

## Place Information Into the Growing Map

During the learning event or focused encoding session:

- Actively test the best attachment point for each new piece under your existing backbone.
- Use non-linear notes to make the expanding network visible.
- Question and compare to strengthen or revise links.
- Prioritise relationships that serve current and future retrieval needs.

The cognitive work happens here: you are building the map, not transcribing the source.

## Handle the Pressures of Active Encoding

Two recurring pressures appear:

- The pull toward linear copying because it feels faster and safer.
- The flood of detail that threatens to bury the backbone.

Return frequently to the Aim questions. Only add detail that answers one of them or meaningfully extends a priority chunk. Update earlier parts of the map as new understanding changes the structure. The visible non-linear record becomes the evidence that real encoding occurred.

## Integration Across the System

Shoot builds directly on Aim and feeds Skin. It prepares multiple meaningful orders for spaced interleaved retrieval and depends on self-management for protected focus blocks. The output is a living map that later stages (Camp reconstruction, Summit execution) can rely on.

Apply Shoot during every main encoding session once Aim is complete. The combination with Skin completes each BHS cycle and compounds across the climb.
