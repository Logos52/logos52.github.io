# Camp I - Core Techniques

Camp I stabilizes the gains from the Ascent climb. The focus shifts from learning new material under guidance to owning the core retrieval and encoding tools so they survive without external structure.

## Primary Tools at This Level

Flashcards move from simple recognition to testing relationships and application. Use them to force reconstruction rather than verification.

Revision becomes active reconstruction of the maps built earlier. Rote memorisation is used only for the small set of items that truly require automaticity; everything else stays tied to the higher-order structure.

Modified method of loci and other spatial techniques provide additional retrieval routes for complex, ordered material.

## Camp I Check and Signals

The checkpoint confirms:

- You can retrieve the backbone and key relationships from memory on demand.
- Flashcard sessions and revision passes produce usable feedback instead of false comfort.
- You notice when rote is creeping in where understanding is still required.

When these signals are weak, the corrective action is more retrieval practice on the actual maps (from Camp I check, Flashcards, Revision, Rote learning and memorisation, and Modified method of loci raws) rather than more passive review. Example: when rote creeps in on relational material, switch to reconstruction of one key relationship using the modified loci route.

## Role in the Overall Climb

Camp I is the first consolidation platform. It proves the system can hold the new methods without constant external scaffolding. Only after this proof does the program introduce the heavier reconstruction and advanced methods of Camp II.

Treat every Camp I session as both practice and diagnostic. The data it produces tells you exactly which pieces of the Ascent maps are solid and which still need targeted Skin or additional Aim work.
