# Error Index

It is compiled from the four places the record was scattered across: the attempt catalog for the context problem, the journal of 2026-08-29 on what not to try, the writing pipeline catalog, and the Fable 5.1 findings of 2026-09-02, plus the memory files and the Trained Contempt session of 2026-09-10. **The check law.** Before proposing or running any fix to writing, search this file for it. If the move is here as dead, it is not proposed, and the reply says which entry it is. If it is here as held, the reply says so and uses it as recorded. A fix that is not here gets a line here the day it is tried, with the owner's ruling verbatim once he gives one. The owner's rule from 2026-08-06 stands: a retry that changes only the date is a violation.
